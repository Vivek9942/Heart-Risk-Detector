# ❤️ Heart Risk Detector (ML Project)

An end-to-end machine learning project that predicts whether a person is at **high or low risk of heart disease** based on medical attributes.

🚀 Live Demo

🔗 Try the App: https://heart-risk-detector-8re6r3w4fwrutdxypzzwet.streamlit.app

## 📌 Project Overview

Heart disease is one of the leading causes of death worldwide. Early prediction can help in timely medical intervention.

This project uses **machine learning classification techniques** to analyze patient data and determine the risk level of heart disease.

## 🎯 Objective

* Analyze medical data to identify key risk factors
* Build a **binary classification model** (High Risk / Low Risk)
* Provide accurate and fast predictions

## ⚙️ Tech Stack

* **Programming:** Python
* **Libraries:** Pandas, NumPy, Scikit-learn
* **Visualization:** Matplotlib, Seaborn
* **Tools:** Jupyter Notebook / VS Code
* **Version Control:** Git & GitHub

## 📊 Dataset

The dataset contains medical attributes such as:

* Age
* Sex
* Chest Pain Type
* Blood Pressure
* Cholesterol
* Maximum Heart Rate
* Exercise Induced Angina

## 🧠 Machine Learning Approach

* Data Cleaning & Preprocessing
* Feature Selection
* Model Training (Classification Algorithm)
* Model Evaluation

## 📈 Model Output

The model predicts:

* 🔴 **High Risk of Heart Disease**
* 🟢 **Low Risk of Heart Disease**
